# 국내 주식 한눈에

yfinance로 국내 주식 10종목의 일봉을 수집하는 한국어 Streamlit 대시보드입니다.

## 보고서 작성 및 SMTP 메일

상단 **보고서·메일**을 선택하고 왼쪽의 주가 조회 기간·저장 데이터 여부를 설정합니다.
대상 기업, 뉴스 검색 기간과 기업별 뉴스 개수를 선택한 뒤 **보고서 작성**을 누릅니다.
주가 순위·수정 종가·수익률·거래량과 뉴스 제목·언론사·발행일·원문 링크를
데이터 기반의 정형 보고서로 작성합니다. 별도 GPT 호출이나 OpenAI 키가 필요하지 않습니다.
기사 본문 분석은 포함하지 않습니다. 뉴스 실패 기업은 보고서에 표시합니다.

보고서 본문과 메일 제목을 수정하고 미리보기 또는 TXT 다운로드로 확인할 수 있습니다.
SMTP 서버, 포트, SSL/TLS 또는 STARTTLS, 발신 이메일 계정, 앱 비밀번호, 수신 주소 1개를
입력한 뒤 **이 보고서를 메일로 발송**을 누르면 해당 내용이 전송됩니다.
CSV 첨부 옵션을 켜면 작성 시점의 주가 요약·뉴스 목록도 첨부합니다.
CSV는 본문을 수정해도 자동 변경되지 않습니다. 기업·기간 변경은 보고서를 다시 작성해 반영하세요.
서버·포트는 메일 제공자의 공식 SMTP 설정에 맞춰 입력합니다.
STARTTLS를 선택하면 포트도 제공자 설정에 맞게 직접 변경해야 합니다.
**연결·인증 테스트 (메일 미발송)** 버튼으로 메일을 보내기 전에 서버 연결과 계정 인증만 점검할 수 있습니다.
SMTP 인사에 `localhost`를 명시하여 컴퓨터 호스트명으로 인한 Gmail의 EHLO 거부를 방지합니다.
Gmail 앱 비밀번호는 붙여넣은 공백을 제거해 인증합니다.
평문 연결이나 인증서 검증 해제는 지원하지 않습니다.

계정·앱 비밀번호와 보고서는 세션 메모리에서만 사용하며 파일·공유 캐시에 저장하지 않습니다.
**SMTP 계정·비밀번호 지우기**로 입력한 인증정보를 제거할 수 있습니다.
동일 수신자·본문·첨부의 반복 발송은 같은 세션에서 차단합니다.
성공 표시는 SMTP 서버 접수를 뜻하며 최종 수신을 보장하지 않습니다.
타임아웃 등으로 발송 여부가 불분명하면 수신함 등을 확인한 뒤 재시도하세요.
검증: `python verify_report_mail.py` (모의 SMTP, 실제 메일 미발송).

## 실행

Windows에서는 폴더의 **홈페이지 실행.cmd**를 더블클릭하세요.
Streamlit을 백그라운드에서 실행하고 기본 웹브라우저를 엽니다.
기존 `localhost:8510` 서버가 정상 실행 중이면 해당 주소를 열고,
포트가 다른 프로그램에 점유되면 8511~8520 중 빈 포트로 실행합니다.
실행 파일과 `launcher.py`, `app.py`, `.venv`는 같은 프로젝트 폴더 안에 두세요.
바탕화면에 두려면 `홈페이지 실행.cmd`의 바로가기를 만들어 사용하세요.
실행 실패 상세 로그는 `launcher-server.log`에서 확인합니다.

현재 폴더에서 PowerShell로 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 http://localhost:8501 을 엽니다. `run.ps1`도 사용할 수 있습니다.

새 환경에서는 Python 3.11 이상을 설치한 후 아래 명령을 먼저 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 기업 공시 (OpenDART)

상단 **기업 공시** → **OpenDART API 키** 입력 → 기업·접수일 기간·유형 선택 → **공시 조회**.
OpenDART에서 발급된 40자리 인증키를 사용하며 OpenAI API 키와 다릅니다.
키는 비밀번호 입력란으로 받고 세션 메모리에서만 사용합니다. 파일·공유 캐시에 저장하지 않습니다.
**OpenDART 키 지우기**를 누르면 키와 조회 결과, 세션 내 기업 코드 매핑도 제거합니다.
공식 `corpCode.xml` ZIP에서 종목코드로 DART 고유번호를 찾아 `list.json`으로 조회합니다.
기존 10종목 각각 조회 가능하며, 주가 API와 독립적으로 동작합니다.
최신순으로 페이지당 최대 100건을 표시합니다. 전체 건수·페이지 수를 확인하고
페이지 번호를 바꿔 다시 조회할 수 있습니다. CSV와 보고서명 필터는 현재 페이지에만 적용됩니다.
최종보고서만 조회 옵션을 끄면 정정을 포함한 제출 보고서를 검색합니다.
접수일·보고서명·제출인·비고·접수번호 및 DART 원문 링크를 제공합니다.
공시 본문이나 재무제표 분석은 이 목록 조회 기능에 포함되지 않습니다.
키 오류·허용 IP·사용 한도·점검·결과 없음 상태를 안내합니다.
검증: `python verify_dart.py` (모의 응답, 실제 키 불필요).
공식 문서: [공시검색](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001),
[고유번호](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018).

## 기업 뉴스 사용

상단 **기업 뉴스**에서 기존 10종목 중 기업을 선택합니다.
Google 뉴스 RSS의 한국어 기업명 검색을 사용하며 별도 API 키는 필요하지 않습니다.
최근 1·7·30일 검색, 제목 키워드·언론사 필터, 최신순 목록, 기사 원문 링크,
필터 결과 CSV 다운로드를 지원합니다. 10분 캐시와 새로고침 버튼을 제공합니다.
검색 제공자가 반환한 범위의 목록으로, 기간 내 모든 기사를 보장하지 않습니다.
기업명 일치에 따른 간접 관련 기사도 포함될 수 있습니다.
주가 조회 기간과 뉴스 검색 기간은 별도이며 주가 수집 없이 뉴스 화면을 사용할 수 있습니다.
**수집된 뉴스에 AI로 질문하기**를 켜고 뉴스 분석용 OpenAI API 키를 입력하면
현재 기업·검색 기간·필터에 해당하는 최신 최대 100건을 바탕으로 질문할 수 있습니다.
모델은 `gpt-4.1-mini`이고, 답변의 `[뉴스 N]`은 기사 목록 및 근거 펼침 영역의 번호와 대응합니다.
기업·기간·필터 또는 실제 기사 목록이 바뀌면 대화가 초기화됩니다.
뉴스는 제목·출처·발행일·링크만 수집하며 기사 본문은 전달하지 않습니다.
따라서 제목 수준의 이슈 정리와 기사 찾기에 적합하며, 자세한 내용은 원문에서 확인해야 합니다.
뉴스 대화는 주가/PDF 대화와 분리되며 API 키는 세션 메모리에만 유지됩니다.
검증: `python verify_news.py`.

## AI 챗봇 사용

상단 **AI 챗봇** 화면에서 OpenAI API 키를 입력하고 질문합니다.
모델은 `gpt-4.1-mini`로 고정되며 OpenAI Responses API를 사용합니다.
키는 비밀번호 입력란으로 받고 현재 브라우저 세션의 서버 메모리에서만 사용합니다.
파일이나 공유 캐시에 저장하지 않으며 **API 키 지우기**로 제거할 수 있습니다.
질문할 때 종목 요약, 종목별 최근 최대 260거래일의 수정 OHLCV,
최근 대화 최대 10개를 OpenAI에 전송합니다. API 사용료가 발생합니다.
요약 수익률은 전체 조회 기간을 반영합니다. 더 오래된 일별 자료는 전송되지 않습니다.
조회 데이터가 바뀌면 대화가 초기화됩니다. **대화 초기화**도 사용할 수 있습니다.
`store=False`로 응답의 API 조회용 저장을 끕니다. 이는 OpenAI의 모든 로그 보관을 끈다는 뜻은 아닙니다.
뉴스·재무정보는 제공하지 않으며 모델의 계산과 해석은 원본 표와 대조하세요.
구현 참고: [OpenAI Responses API](https://developers.openai.com/api/reference/python/resources/responses/methods/create).

## 별도 수집 및 검증 명령

### PDF 질문하기

화면 상단 **PDF 챗봇** → PDF 업로드 → OpenAI API 키 입력 → 질문 순서로 사용합니다.
PDF 챗봇은 주가 수집 없이 독립적으로 동작합니다.
기존 **AI 챗봇**에서도 PDF를 올리고 **PDF만 / 주식 데이터만 / PDF + 주식 데이터**를 선택할 수 있습니다.
문서 1개당 최대 25MB·1,200페이지를 지원합니다. PDF는 파일로 저장하거나 공유 캐시하지 않고
세션 메모리에서 읽습니다. 업로드 제거 시 추출 문서와 대화도 제거됩니다.
질문 시 관련 발췌 최대 8개와 최근 대화를 OpenAI로 보냅니다. PDF 원본은 OpenAI Files에 업로드하지 않습니다.
한국어 단어·글자 조합 검색이므로 의미가 비슷한 표현을 놓칠 수 있습니다.
전체 요약은 대표 발췌를 바탕으로 하며 완전한 전수 요약이 아닙니다.
답변은 `[PDF p.112]` 같은 페이지 인용을 사용하고, **답변에 전달한 PDF 근거 보기**에서 발췌를 확인할 수 있습니다.
페이지는 PDF 뷰어의 1부터 시작하는 순서로, 인쇄된 쪽수와 다를 수 있습니다.
텍스트 추출 방식이므로 스캔·이미지·복잡한 표는 OCR 또는 원문 확인이 필요합니다.
암호화·손상 PDF, 읽을 수 없는 문서는 안내 메시지를 표시합니다.

PDF 업로드 검증(실제 OpenAI 호출 없음):

```powershell
.\.venv\Scripts\python.exe verify_pdf.py '샘플문서.pdf'
```
